# ADR-009: Per-source failure isolation and atomic publish

- **Status:** ACCEPTED
- **Feature:** energy-news-newsletter
- **Requirements:** FR-2, NFR-1, NFR-7

## Context

Individual feeds break often; a partial run must not degrade the live newsletter.

## Decision

Fetcher never raises per source; the run continues and records FAILED or STALE_SOURCE. Publisher pushes gh-pages only after every stage and size guard succeed, in a single commit; otherwise the last good build stays live and the stale banner appears after 30 h.

## Consequences

Positive: readers always see a coherent page. Negative: one failing late stage delays all updates until fixed.
