# ADR-016: News-only v1; price module dormant behind a flag

- **Status:** ACCEPTED
- **Feature:** energy-news-newsletter
- **Requirements:** FR-8, NFR-9

## Context

The owner decided price data is not important yet; the goal is to read reputable sources and condense the hottest topics.

## Decision

Drop price effects, benchmark changes and price badges from v1 outputs (FR-8 WONT). Keep price code isolated behind settings prices.enabled (default false) so it can return without restructuring.

## Consequences

Positive: less scope, no EIA key needed, faster to launch. Negative: the analysis cannot connect news to market moves until prices return.
