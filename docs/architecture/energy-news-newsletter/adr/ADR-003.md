# ADR-003: LLM confined behind LLMPort with API adapter

- **Status:** SUPERSEDED
- **Feature:** energy-news-newsletter
- **Requirements:** FR-4, FR-11, NFR-2, NFR-3

## Context

Classification, figure proposal and summarisation need language understanding, but LLM output is non-deterministic, costs money and can invent labels.

## Decision

All model calls go through LLMPort, which enforces a per-run token budget, caches by (prompt_version, content_hash), and has a deterministic stub adapter. Callers validate outputs against closed taxonomies and grounding rules and flag failures rather than accept them. SUPERSEDED on 2026-09-16 by ADR-014 (no LLM API; all generative work in the Claude scheduled task).

## Consequences

Positive: re-renders are byte-identical, cost is capped, tests run offline. Negative: prompt changes require a prompt_version bump that invalidates the cache.
