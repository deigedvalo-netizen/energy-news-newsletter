# ADR-002: Figures quoted verbatim; all scores computed by pure functions

- **Status:** ACCEPTED
- **Feature:** energy-news-newsletter
- **Requirements:** FR-6, FR-7, FR-9, NFR-5

## Context

Energy news is dense with numbers. An LLM paraphrase or unit conversion that silently alters '4.1 million barrels' would mislead a trader and cannot be detected downstream.

## Decision

FigureExtractor keeps a figure only if its span is an exact substring of allowed source text and never converts units. Relevance, trend status, trajectory and hotness are pure functions with no LLM involvement.

## Consequences

Positive: every pipeline-produced number is traceable and testable. Negative: some valid figures are dropped when phrasing varies.
