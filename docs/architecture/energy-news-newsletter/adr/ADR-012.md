# ADR-012: Trader analysis: interpretation allowed, forecasts and trade ideas not

- **Status:** ACCEPTED
- **Feature:** energy-news-newsletter
- **Requirements:** FR-16, FR-17, FR-15

## Context

The owner wants an explanation of what all collected news means for energy traders, which requires interpretation. Unconstrained interpretation drifts into invented facts, price forecasts and trade ideas. Three options were weighed: (a) deterministic templates only, which are verifiable but read as data dumps; (b) an LLM analysis inside the pipeline, which would need an API key; (c) the daily Claude task writes the analysis once a day from a precomputed synopsis, passing the same validator as issues.

## Decision

The daily Claude task writes the analysis from the digest, the computed trend trajectories and the articles it opened. It may explain in general, conditional terms how developments are usually read, but the validator rejects links absent from the digest, forecast patterns and advisory language. When no analysis based on data from the last 36 hours is published, pinned cards show the data-only synopsis.

## Consequences

Positive: readers get narrative context while every checkable claim remains traceable to collected data. Negative: general explanatory statements cannot be verified mechanically; they rely on the prompt rules and are visible for human review in the issues/analysis history. Some legitimate phrasing will be rejected by the forecast patterns.
