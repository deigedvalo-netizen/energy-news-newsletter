# ADR-018: Reputable source policy: tiers, types and verification from the runner

- **Status:** ACCEPTED
- **Feature:** energy-news-newsletter
- **Requirements:** FR-1, FR-2, FR-18

## Context

The owner wants mostly tier-1, well-checked sources. Wire services (Reuters, Bloomberg, AP) and price reporting agencies (Platts, Argus) need licenses. Several reputable feeds could not be checked from the planning environment.

## Decision

Tier 1 = official or primary publishers and news organizations with a public editorial and corrections policy; tier 2 = specialist trade press and press-release wires; tier 3 = aggregators, disabled. Each source records source_type and terms_note. Official sites without RSS use HTML_LIST adapters. The first run report confirms each feed from the GitHub runner; failing sources are fixed or disabled by the owner.

## Consequences

Positive: a defensible, documented source list that can grow. Negative: licensed wire services stay out; HTML_LIST selectors need occasional maintenance when official sites redesign.
