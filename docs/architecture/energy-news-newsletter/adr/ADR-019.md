# ADR-019: Hosting on GitHub Pages with a custom domain, noindex and a private-preview banner

- **Status:** ACCEPTED
- **Feature:** energy-news-newsletter
- **Requirements:** FR-20, NFR-4, NFR-9

## Context

The newsletter is for the owner and a friend, may grow, and the owner can buy a domain. GitHub Pages sites on free plans are public.

## Decision

Publish to GitHub Pages with an optional CNAME from settings and HTTPS enforced. Add noindex meta, robots.txt Disallow and a banner stating it is a private preview with unverified, informational content that is not investment advice. If real access control is needed, put the domain behind Cloudflare Access or move hosting to a private host; the pipeline is unchanged.

## Consequences

Positive: free, simple, custom-branded. Negative: anyone with the URL can read it; digest JSON is publicly fetchable.
