# ADR-001: Daily batch pipeline publishing a static site

- **Status:** ACCEPTED
- **Feature:** energy-news-newsletter
- **Requirements:** NFR-1, NFR-3, FR-2, FR-10

## Context

A handful of readers, 25-35 reputable sources and a free-tier budget. The owner confirmed on 2026-09-16 that daily updates are enough, replacing the earlier 3-hour cadence. An always-on service and an agent-only design were evaluated.

## Decision

Run one deterministic Python pipeline daily at 05:00 America/Chicago on GitHub Actions that scans, tags, clusters and builds the digest, then renders static HTML to GitHub Pages. Interactivity is client-side over prebuilt JSON.

## Consequences

Positive: zero hosting cost, low load on sources (one request per feed per day), reproducible builds. Negative: news is up to a day old; breaking stories wait for the next run.
