# ADR-014: No LLM API: generative work runs only in the Claude scheduled task on the owner's subscription

- **Status:** ACCEPTED
- **Feature:** energy-news-newsletter
- **Requirements:** FR-4, FR-11, FR-14, NFR-2, NFR-3

## Context

The owner prefers to use an existing Claude subscription instead of paying per token. The earlier design allowed an optional API adapter inside the pipeline for classification and summaries.

## Decision

Remove the LLM API adapter and keys. The pipeline is fully deterministic: keyword taxonomies, an organizations alias file, TF-IDF clustering and extractive summaries. Naming trends, writing the newsletter and writing the analysis happen once a day in the Claude scheduled task, bounded to one compact digest (<= 60 KB) and at most 15 opened articles.

## Consequences

Positive: zero API cost, simpler secrets, fully reproducible pipeline. Negative: tagging quality is limited to keyword rules; plan usage limits can occasionally block a daily run (fallback: synopsis and previous newsletter).
