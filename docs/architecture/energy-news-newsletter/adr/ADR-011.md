# ADR-011: Immutable snapshots and least-privilege authoring

- **Status:** ACCEPTED
- **Feature:** energy-news-newsletter
- **Requirements:** FR-14, FR-15, FR-19, NFR-2, NFR-6, NFR-8

## Context

feed.json is rewritten every 3 hours, so an issue validated against the live feed could fail or pass by accident. The authoring task also holds repository write access through the connector.

## Decision

Publisher writes content-addressed snapshots with a latest.json pointer and 30-day retention; issues must reference a snapshot hash. The task's instructions restrict it to issues/ (newsletter, analysis, index.json, trends.json), and IssueScopeGuard enforces this in CI by reverting task-authored commits touching any other path. Issue dates are never overwritten.

## Consequences

Positive: validation is exact and repeatable; a misbehaving task cannot alter pipeline code, data or the live site. Negative: extra storage for snapshots (small, bounded by NFR-6) and a CI workflow to maintain.
