# ADR-007: Bounded storage with retention and a 50 MiB guard

- **Status:** ACCEPTED
- **Feature:** energy-news-newsletter
- **Requirements:** NFR-6, NFR-7, FR-19

## Context

The owner's earlier tracker stalled when a committed database approached GitHub's 100 MiB per-file hard limit and pushes silently failed.

## Decision

Persist SQLite on a single-commit data branch and the site on a single-commit gh-pages branch with 30-day raw-article retention and VACUUM each run; Publisher refuses to push any file over 50 MiB and raises STORAGE_LIMIT; the published site carries only derived JSON and HTML. Snapshots and digests are retained 30 days so ledger mentions can be validated.

## Consequences

Positive: growth is bounded and failure is loud rather than silent. Negative: raw articles older than 30 days cannot be re-clustered.
